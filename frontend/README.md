# Frontend

React single-page application: user choice, course tree, chat, and a
Markdown document column (see [arc42 chapter 1, User Interface](../docs/arc42/01-introduction-and-goals.adoc)).

In the development setup (see the [README](../README.md)) Vite serves
it on :5173 and proxies `/api` to the backend. The application image
builds it and the backend serves it.
