== Context and Scope

// The system boundary: which communication partners exist, and what
// crosses the boundary. Business context first, technical context
// only where the protocol or channel matters.

The system is one self-hosted instance. Its file storage is part of
it and deployed with it; it is not a communication partner.

=== Business Context

....
include::diagrams/business-context.puml[]

[cols="1,2,2", options="header"]
|===
| Partner | Input to the system | Output from the system

| Student
| Choice of user, course PDFs and notes, chat messages and answers,
  self-ratings for Tier B tasks
| Tutoring and grading in chat, the state of each ingestion, all
  Markdown files of the course for reading

| Operator
| Deployment, instance configuration including the Anthropic and
  Mistral API keys, users, and optionally course PDFs and `notes.md`
  through the command line
| A running instance

| Anthropic API
| Topics with the block ranges of their tasks, tutor replies and
  grading, completed steps
| Converted course material with its figures, topics, artifacts, and
  prompts -
  authenticated with the instance's API key

| Mistral OCR API
| The Markdown of each course PDF, with its figures as images
| Course PDFs - authenticated with the instance's Mistral API key
|===

The student's course material leaves the instance only towards the
Anthropic API and the Mistral OCR API.

=== Technical Context

[cols="1,1,3", options="header"]
|===
| Partner | Channel | Notes

| Student
| Browser, HTTP
| Web UI over a JSON HTTP API. A chat message is a `POST` carrying
  the chat's transcript, whose response streams the reply and its tool events as Server-Sent
  Events. Open chats are loaded and ended with their own requests.
  Course PDFs and notes are uploaded as multipart requests.

| Operator
| Docker host
| docker-compose, `.env`, and the user and course commands of
  the application image (chapter 8). Course material for the course
  commands is read from the directory `courses/` next to the compose
  file.

| Anthropic API
| HTTPS
| Outbound only. Requests carry converted course material as text and
  its figures as images. Every request
  carries the instance's API key.

| Mistral OCR API
| HTTPS
| Outbound only, during ingestion. A request carries one PDF and the
  instance's Mistral API key.
|===
